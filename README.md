# Azamat Apsamatov — Portfolio Landing Page

Static portfolio website built with plain HTML, CSS and JavaScript.

## Run locally
Open `index.html` directly, or from this folder run:

```bash
python3 -m http.server 8080
```

Then open http://localhost:8080

## Deploy
Upload the contents of this folder to the web root for `azamat.co`.

## Files
- `index.html` — content and structure
- `styles.css` — visual design and responsive layout
- `script.js` — navigation, reveal animations and network canvas background
- `assets/Azamat_Apsamatov_Resume.pdf` — downloadable resume
